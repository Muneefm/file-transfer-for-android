# File Transfer for Android

Support and privacy policy pages for **File Transfer for Android**, a Mac app by Kolice LLC that copies photos, videos and files between an Android phone and a Mac over USB.

- Support: https://muneefm.github.io/file-transfer-for-android/
- Privacy policy: https://muneefm.github.io/file-transfer-for-android/privacy.html
